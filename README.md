# Pygame Space Shooter

Game space shooter 2D sederhana yang dibuat dengan Python dan Pygame.

## Tentang Proyek

Game ini dibuat secara sederhana dan source code-nya dibagikan untuk membantu para pemula mengeksplorasi cara kerja sebuah game komputer sederhana.

## Fitur

- Gameplay space shooter 2D yang sederhana
- Pergerakan pemain dapat dikendalikan dengan keyboard
- Tembakan peluru dan objek rintangan
- Skor, nyawa, dan perkembangan level
- Tingkat kesulitan yang meningkat seiring bertambahnya skor
- Game Over dan fitur mulai ulang (restart)
- Tidak memerlukan aset sprite eksternal.

## Cara Download dan Main

1. Download `SpaceShooterV1_0.zip` dari halaman [Releases](../../releases).
2. Extract file ZIP.
3. Buka folder yang di-extract.
4. Jalankan `SpaceShooter.exe`.

**Catatan:** 
- Pastikan file executable dan file/folder pendukungnya tetap dalam satu folder setelah di-extract.
- File executable ini dirancang untuk dapat berjalan tanpa memerlukan instalasi Python terpisah.
- Game hanya dapat dimainkan di komputer dengan sistem operasi Windows 10/11.

## Kontrol

| Tombol            | Aksi                                     |
| ----------------- | ---------------------------------------- |
| SPACE (SPASI)     | Memulai game / Menembak                  |
| LEFT (KIRI) / A   | Menggerakkan pemain ke kiri              |
| RIGHT (KANAN) / D | Menggerakkan pemain ke kanan             |
| R                 | Memulai ulang (restart) setelah Game Over|
